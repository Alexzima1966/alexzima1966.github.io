⚙️ Настройки алгоритма параметры V10

V10 считает f_exp_home/away из линии тотала и супрематии (1.8·(p1−p2)). Режим «МНК» подбирает λ так, чтобы матрица совпала со всеми котировками O/U и 1X2 — это расширение, точнее.
Поправка низких счётов. V10: сетка −0.16…+0.06, по умолчанию −0.06.
V10 предсказывает таймы отдельными моделями; здесь λ делится константой (влияет только на IY/2Y-рынки).
Сканер V10 использует 65%; 60% ≈ на 5 п.п. выше базовой частоты BTTS. Работает для «ДА» и «НЕТ».
Value = EV и отрыв от рынка. EV и edge требуют «Глубокого анализа» (котировки ОЗ).
Отсечка тривиальных ставок (кэф < 1.30) — исправление слабости оригинала.
xG даёт независимые от рынка λ — только так можно найти перевес над ценой ОЗ.
1 запрос /Odds на матч. Лимит sstats ≈ 20 запросов/мин.
Ставка = доля банка по Келли (кап 5%) — показывается в столбце «ставка».
Ставка попадает в купон, если и EV, и отрыв модели от рынка не ниже этих порогов.
Кнопка «🏅 ТОП МАТЧИ» показывает 2–3 самых уверенных матча дня. Уверенность = 60% вероятность модели + 40% нижняя граница Уилсона (честная частота), плюс бонус за зелёный класс.
Встроенный снимок (14 дней) работает без API. При наличии ключа бэктест подтягивает завершённые матчи с полным рынком и считает реальный ROI по котировкам ОЗ.
Порог входа в историческую ставку. Считается по лучшей цене ОЗ и по каждой конторе отдельно.
CLV (Closing Line Value) сравнивает кэф вашей ставки с закрывающей линией. Плюсовой CLV — главный признак перевеса над рынком.
1 запрос на день (до 500 завершённых матчей с котировками). 14 дней ≈ 2400 матчей; 45+ дней нужны, чтобы отдельно калибровать молодёжку и женские лиги.
Все константы V10 (caps 4/5, ρ, бины, Wilson z=1.0, групповые 0.85/0.68, cap 0.94, floor 0.56, n≥150) зашиты в движок.

📊 Самокалибровка на завершённых матчах

Как в V10: прогнозы строятся по завершённым матчам, затем данные делятся хронологически 70% / 30%. На первых 70% обучается изотоника по каждому из 86 рынков, на последних 30% (lockbox) считаются фактические частоты, нижние границы Уилсона и групповые пороги цветов. Никаких «нарисованных» процентов.

👥 Качество по классам лиг честные частоты и пороги считаются отдельно для взрослых, молодёжи и женских лиг

🧪 Бэктест на истории

Прогоняем движок V10 по завершённым матчам: λ из котировок → матрица → изотоника → P(ОЗ). Встроенный снимок (14 дней, 2400 матчей) работает без API и показывает качество модели (logloss, Brier, калибровку) и условный ROI по «цене закрытия». Если есть ключ sstats.net, бэктест подтягивает завершённые матчи с полным рынком и считает реальный ROI по каждой конторе.

📈 CLV-мониторинг

CLV (Closing Line Value) — сравнение кэфа вашей ставки с закрывающей линией. Если линия двинулась в вашу сторону (кэф вырос), вы взяли цену лучше рынка: это главный практический признак перевеса. Программа хранит ставки в браузере, подтягивает текущие котировки по каждой конторе и считает CLV, P/L и долю плюсовых линий.
