📋 Стратегия «Гол во 2-м тайме»

🟢 Источник: SStats.net (Flashscore + букмекеры)

ЭндпоинтКакие данные берём
/Games/list?Live=trueМониторинг live-матчей, статус 4 = перерыв → запуск анализа
/Games/{id}Счёт 1-го тайма (homeHTResult/awayHTResult), удары в створ 1Т, угловые 1Т, удары всего, xG, владение
/Odds/{gameId}Резерв доматчевого кэфа ТБ 2.5 — медиана по всем букмекерам (устойчива к выбросам, в отличие от среднего)
/Odds/live/{gameId}Резерв live-кэфа «2-й тайм, ТБ 0.5» — эквивалент «Match Goals Over (N+0.5)» (тотал матча, N = голов на перерыве) и рынки 2-го тайма, Bet365
/Games/last-games-stats?limit=6Форма (В/Н/П) и голы (ГЗ/ГП) обеих команд за последние 6 матчей
/Games/glicko/{id}Вероятности по Glicko-2 — в модальное окно сигнала
/Games/text-summaryТекстовая сводка — в модальное окно сигнала

🟣 Источник: Pari.ru (через API SStats, обновление 3–10 сек)

ЭндпоинтКакие данные берём
/Pari/matches?live=trueСопоставление матча SStats ↔ eventId Pari по названиям команд (кэш на цикл)
/Pari/events/{eventId}Опасные атаки 1-го тайма (события DangerousAttack, period=1) — основной источник; резерв: удары в створ, угловые
/Pari/match/{eventId}Доматчевый кэф ТБ 2.5 — prematch «Full Time. Goals Total: Over 2.50» (реальный кэф в конторе, где делается ставка); live-кэф «2-й тайм, ТБ 0.5» — «Second Half. Goals Total: Over 0.50», резерв — «Full Time. Goals Total: Over (N+0.5)» (математический эквивалент: гол во 2-м тайме ⟺ тотал матча ≥ N+1); сверка счёта 1Т

⚠️ Почему два источника: у SStats (Flashscore) поле dangerousAttacks часто равно null, зато удары в створ и угловые — точные (проверено: 5 в створ против 1 у Pari, 7 угловых против 4). У Pari, наоборот, полный лог опасных атак (проверено: 66 за 1Т). Программа берёт каждый показатель из надёжного источника и показывает происхождение каждой цифры.

📢 Push-уведомления: ntfy.sh

Сигнал отправляется POST-запросом на https://ntfy.sh в топик из настроек. Подпишитесь на топик в приложении ntfy (Android/iOS) или в веб-интерфейсе ntfy.sh.

🌐 Все запросы к API проходят через планировщик с лимитом 28 запросов/мин (макс. 30 — ограничение SStats.net без API-ключа). Приоритет: live-список → перерывы → статистика/кэфы → форма → обогащение сигнала. При провале счёта/лиги/доматчевого кэфа остальные проверки не тратят запросы (быстрый отказ).
