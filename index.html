🧪 Проверить модель по нескольким лигам

Лиги выбираются по времени ближайшего матча из исходного набора расчёта, независимо от качества прогноза. Дополнительные запросы SStats; проверка может занять минуты.

После расчёта кандидатов можно запустить проверку.

Сравнение одной модели с равновероятным 1X2, не с букмекером. Нет подтверждённых исторических временных меток линии; ROI не оценивается. Пропуски и недостаток истории могут исказить результаты.

Журнал прогнозов

Хранение в памяти или на устройстве по вашему выбору; экспортируйте резервную копию.

Выключено. Без экспорта записи исчезнут при закрытии или перезагрузке страницы.

Ключ API не сохраняется. Доступ к журналу могут иметь другие пользователи этого браузера; очистка данных браузера может удалить копию. Рекомендуется регулярно скачивать JSON.

Без автосохранения записи находятся только в памяти вкладки. Время фиксации — время устройства после проверки SStats, не время обновления цены у букмекера. Коэффициент может быть устаревшим или недоступным. Импорт объединяет записи по ID; файл содержит историю, но не API-ключ. Результаты не являются проверкой доходности.

🔎 Фильтры анализа

Фильтры меняют только анализ, не удаляют записи и не влияют на общий счётчик или экспорт. Сначала выбирается самый ранний снимок пары матч + исход, затем применяются фильтры по этому снимку.
